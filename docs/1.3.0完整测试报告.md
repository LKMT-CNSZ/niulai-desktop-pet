# 牛来盯盘 1.3.0 完整测试报告

测试日期：2026-08-23  
测试平台：Windows 11 x64，单显示器，系统缩放 150%，可用工作区 1707×1067 DIP

## 结论

1.3.0 的自动回归、真实 Electron 窗口测试、65 秒持续巡游测试、单实例测试和 Windows 打包前检查均通过。新版主角色为一个连续重建并蒙皮的网格，不再由基础几何体拼装；第三版几何牛保留为第一级故障回退。

## 回家连续性

实机记录的状态顺序为：

`HOME_SLEEPING → HOME_WAKING → HOME_EXITING → ROAMING → RETURNING → ENTERING_HOME → HOME_SLEEP_ENTER → HOME_SLEEPING`

测试期间移动了家的坐标，牛使用更新后的目标返回；巡游窗口与家门坐标最终一致，牛进入睡眠后巡游窗口隐藏并销毁，没有瞬移或残留窗口。

## 性能

| 场景 | 实测速率 |
| --- | --- |
| 普通3D、最大60 FPS | 约56.9 FPS |
| 省电3D | 约29.5 FPS |
| 休盘3D睡眠 | 约11.9 FPS |
| 2D省电睡眠 | 约8 FPS |

65秒持续巡游共采样7次，最终巡游渲染约28.9 FPS。相对第5秒采样：主进程私有内存减少约19.4 MB，家园渲染器减少约7.4 MB，巡游渲染器减少约1.6 MB，没有持续增长；鼠标穿透始终为开启。自动退出后没有残留本项目 Electron 进程。

## 显示器与DPI

- 当前机器对单显示器、150%缩放进行了真实窗口验证。
- 自动几何测试覆盖100%、125%、150%缩放，任务栏位于上、下、左、右，副屏位于主屏左侧或右侧、负坐标工作区、默认单屏巡游和可选跨屏巡游。
- 自动行为测试以30 FPS与60 FPS分别运行，相同时间内位置一致；覆盖提前减速、受限转向、无边缘瞬间反弹、拖动后重规划和30分钟确定性长跑。
- 显示器断开、分辨率改变和恢复采用模拟系统事件验证安全回家；本机没有第二台物理显示器，因此真实双屏热插拔仍需目标设备复验。

## 已知限制与人工验收项

- 当前连续模型来自参考图多视图重建和自动蒙皮，适合约80至220像素桌宠观看；600像素近看仍能看到自动重建表面和顶点颜色的限制，不等同于电影原始模型或人工影视级拓扑。
- 本机没有执行真实的系统睡眠/锁屏，也没有物理双屏热插拔，以免中断用户桌面；已用相同恢复入口完成模拟测试。
- 持续运行自动测试为65秒，未替代8小时以上人工挂机验收。
- Windows安装包未做商业代码签名，首次运行可能出现 Microsoft SmartScreen 提示。
- 角色参考图和原声音频的复制、传播及商业使用权由素材提供者确认；软件本身不会上传股票、持仓或用户偏好。
- 鼠标实际手感、跨不同显卡驱动的透明窗口表现和企业安全软件兼容性，仍应在最终安装包上做一次人工体验确认。

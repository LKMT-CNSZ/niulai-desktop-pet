# 牛来盯盘：本地特色功能系统

## 默认行为与兼容性

- 情绪记忆、收盘总结、安静办公默认关闭。
- 用户提醒列表默认为空。
- 旧版 `niulai:pet-settings`、持仓、标的和行情事件配置字段含义不变。
- 所有情绪、日内统计和提醒设置只写入本机 `localStorage`，不会上传，也不会反向修改行情或持仓数据。

## 模块边界

- `emotion-memory.js`：根据行情、持仓和已确认行情事件维护每日情绪值，只输出待机动作偏好、动作倍率和吐槽候选。
- `daily-session.js`：记录当日最后涨跌幅、今日持仓盈亏、最大浮盈、峰值后的最大回撤，以及相邻行情样本中最明显的拉升或跳水。
- `alert-trigger-engine.js`：规范化并评估用户提醒；使用阈值穿越、事件匹配和每条提醒独立冷却，避免价格抖动重复提醒。
- `quiet-office.js`：判断上海时区的用户时间段，并产生静音、低特效、低巡游频率的运行时策略；不覆盖用户保存的原始音量和特效强度。
- `renderer.js`：将上述模块的输出路由到行情牌、2D动作、3D演出、声音和面板；真实行情对象只作为只读输入。
- `roaming-behavior.js`：只接收情绪待机偏好与安静模式参数，不读取行情和持仓。

## 本地存储

- `niulai:pet-settings`：新增 `emotionMemory`、`closeSummary`、`quietOffice`。
- `niulai:emotion-memory-v1`：当天五种情绪值及主情绪。
- `niulai:daily-session-v1`：当天收盘统计和是否已展示。
- `niulai:alert-triggers-v1`：最多20条用户提醒。

跨自然日后，情绪与日内统计会自动建立新的一天；历史日数据不会参与新一天计算。

## 提醒规则

支持价格、涨跌幅、回到成本、累计盈亏金额、快速拉升和快速跳水。价格、涨跌幅和盈亏金额采用阈值穿越触发；快速事件复用现有行情事件引擎。每条提醒至少有15秒冷却，界面新建提醒默认60秒。

- 仅行情牌：显示微型提醒，不切换形态。
- 2D动作：仅在2D牛当前可见时播放，不会强制隐藏3D牛。
- 3D演出：当前已经是3D时直接调度；自动双形态且允许自动演出时可请求3D出场。手动2D、省电或安静模式不会被强制切换。
- 声音：只有用户为该提醒明确勾选时才允许播放；安静办公时始终静音。

## 安静办公策略

支持普通时间段和跨午夜时间段。启用期间：

- 运行时音量为0，但不覆盖用户保存的音量。
- 特效强度限制为轻量级，主行情事件只用表情、小动作和行情牌提醒。
- 巡游进入省电节奏并延长停留时间，运行速度按保守比例降低。
- 自动3D行情演出受到省电策略限制。

时间段结束后，软件自动恢复用户原来的音量、特效、巡游速度和省电设置。

## 收盘总结

只有用户开启且当天收到过有效开盘行情样本时才展示；每天最多自动展示一次。关闭卡片不影响回家睡眠流程，点击“关闭以后自动展示”会立即关闭该功能。

牛来盯盘 1.2.1｜产品介绍
========================

产品名称：牛来盯盘
产品类型：A股行情桌面宠物
适用平台：Windows 10 / Windows 11 x64


一、产品简介

“牛来盯盘”是一款将股票行情、持仓盈亏与桌面宠物结合的轻量化桌面应用。

软件以一只半眯眼、粉色大嘴的搞怪牛为主角，将传统行情数字转换成直观的动作、声音和趣味特效。用户无需一直打开大型行情软件，也能在桌面角落实时了解关注标的的涨跌状态。

牛来盯盘采用 300×300 透明置顶控制窗口，不占用任务栏空间。用户可以自由移动挂件，在工作、学习或娱乐过程中随时查看行情。


二、两种显示形态

1. 2D 趴窗牛

牛会趴在透明窗口边缘看着用户，支持呼吸、眨眼、休盘困倦、上涨上探、下跌低落以及趣味互动动画。

该模式资源占用较低，适合长期放置在桌面角落。

2. 3D 动态漫游牛

选择 3D 模式后，原来的 300×300 挂件会留在原位，作为行情、持仓和互动控制台。3D 牛进入独立透明漫游层，在当前屏幕的可用桌面区域自由行走。

漫游窗口仅覆盖牛自身附近，不使用全屏透明遮罩，因此不会阻挡其他软件。用户可以在设置中调节漫游速度，从慢速散步到快速奔跑。

牛身后具有柔和的局部暗色轮廓，可降低网页、文档和代码文字对模型显示的干扰，同时保持窗口边缘透明。


三、实时行情监控

软件支持输入任意 A 股代码，例如：

- sh000001：上证指数
- sz399001：深证成指
- sz399006：创业板指
- sh600519：贵州茅台
- sz000001：平安银行

用户也可以输入六位数字，软件会自动识别上海或深圳市场。

左上角行情卡显示股票名称、代码、现价和涨跌幅。点击行情卡可以进一步查看昨日收盘、今日涨跌、成交量、成交额、数据来源和持仓盈亏。

上涨使用红色，下跌使用绿色，符合 A 股常用显示习惯。


四、持仓盈亏换算

用户可以在设置中填写持仓成本价和持股数量。软件会自动计算：

- 今日盈亏
- 累计盈亏
- 累计盈亏率

盈亏结果还会转换成更直观的生活单位，例如鸡腿、奶茶、火锅、手机或“连续吃土”，让看盘过程更轻松有趣。

所有持仓信息仅保存在用户本机，不会上传到服务器。


五、行情状态与动作

1. 休盘
   牛会进入安静的睡眠或困倦状态，并保持静音。

2. 平盘
   牛保持呼吸和轻微待机动作。

3. 上涨
   牛会表现出积极、冲刺或庆祝动作，头顶显示红金上涨特效。

4. 下跌
   牛会低头、缓慢行走或表现出受挫动作，头顶显示绿色下跌特效。

5. 极端行情
   大涨时可能触发金币雨和高亮光环；大跌时可能出现绿色发带、泡面或剧烈颤抖彩蛋。


六、点击发声

牛来盯盘不会因为行情刷新或涨跌切换主动发声，避免在办公或夜间使用时突然播放声音。

- 行情上涨时点击牛：播放一次“牛来”。
- 行情下跌时点击牛：播放一次“妈妈”。
- 收盘后仍按当天最后一次成功获取的所选股票涨跌幅播放“牛来”或“妈妈”；
- 平盘、当天尚无行情或行情未连接时：点击不发声。

用户可以在设置中调整音量或彻底关闭声音。


七、趣味互动

- 单击牛身：触发开心摇摆或甩尾动作。
- 快速连点三次：触发暴躁冲锋与鼻孔烟雾。
- 鼠标悬停：随机出现股民吐槽气泡。
- 上香：升起三炷赛博香并祈祷十五秒。
- 3D 漫游上香：牛立即停在原地，转身正面对着用户完成祈祷，结束后继续漫游。
- 喂大阳线：触发咀嚼、金币和爱心特效。
- 喂大阴线：触发摇头、干呕和绿色嫌弃气体。
- 滚动鼠标滚轮：在上证指数、深证成指和创业板指之间快速切换。


八、个性化设置

用户可以调整：

- 监控股票代码
- 持仓成本和持股数量
- 2D 或 3D 显示形态
- 总音量与声音开关
- 动作幅度
- 模型大小
- 特效强度
- 3D 漫游速度
- 行情卡显示
- 省电模式

所有设置会自动保存在本机，下次启动时继续使用。


九、设计特点

- 透明无边框窗口
- 300×300 轻量控制台
- 始终置顶但不占用任务栏
- 2D 与 3D 双形态
- 独立局部3D漫游窗口
- 窗口尺寸自动校正
- 单实例保护，避免重复打开
- 行情断线自动重试
- 退出前二次确认
- 本地保存持仓与设置


十、适合人群

- 希望工作时轻量查看行情的用户
- 喜欢桌面宠物和趣味交互的股民
- 不希望大型行情软件长期占据屏幕的用户
- 希望用更轻松方式观察持仓盈亏的用户


十一、数据与风险说明

软件使用公开行情接口，数据可能存在延迟、缺失或临时不可用。持仓盈亏为本地数学换算结果，仅供展示与娱乐，不构成投资建议、交易指令或收益承诺。

进行任何交易前，请以券商正式交易系统提供的数据为准。


十二、模块化说明

行情与持仓、2D 牛、3D 牛、行为状态、动作调度、特效、音频、设置存储、家园窗口和漫游 IPC 已划分独立边界。本次整理不更换 3D 模型、不改变现有设置字段含义，也不新增桌面巡游行为。2D 趴窗牛使用独立图片素材，可不依赖 3D 模型运行。

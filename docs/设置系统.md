# 牛来盯盘设置系统

## 界面结构

设置抽屉按 11 个可折叠分组排列：股票与自选、持仓、2D/3D 模式、桌面巡游、回家与睡眠、声音、动作、特效、性能、提醒触发器、数据与隐私。底部保存、取消和恢复默认按钮固定可见，主窗口退出按钮始终位于抽屉上层。

“提醒触发器”组打开既有特色功能页，用于管理提醒、情绪记忆、收盘总结和安静办公时间，不重复创建第二份数据。

## 保存、取消与恢复默认

- 保存：校验股票代码和持仓后，将表单一次性写入本机存储并应用到当前运行状态。
- 取消：重新读取已保存数据，丢弃本次未保存改动。
- 恢复默认：只把默认值填入表单；用户再次点击保存后才真正写入。
- 一键召回：属于即时命令，不需要先保存设置。

## 兼容与默认值

旧版键名 `niulai:selected-symbol`、`niulai:portfolio`、`niulai:pet-settings` 保持不变。原有字段不会改名或改变含义。读取旧数据时，仅对缺失的新字段补充安全默认值：

- 允许桌面巡游：开启；
- 允许跨显示器：关闭；
- 巡游频率：100%；
- 演出后自动回家：开启；
- 极端行情完整演出：开启，以保持旧版本既有行为；
- 模型质量与特效质量：均衡；
- 最大帧率：60 FPS，省电模式仍会使用更低的实际刷新上限；
- 自动双形态：不强制启用，沿用用户原显示形态。

旧版 `autoContinueRoaming` 会兼容换算为界面中的“演出后自动回家”，保存时仍同步保留旧字段，避免老版本读取失败。

## 省电推荐

启用省电模式时，界面展示 30 FPS、低模型质量、低特效质量和 55% 巡游频率的推荐组合。推荐只是一键填表建议；除非用户点击“应用推荐”并保存，否则不会覆盖任何手动值。

## 数据与隐私

股票代码、持仓成本、持股数量、提醒条件和显示偏好只保存在当前设备的 Electron 用户数据目录中，不通过本软件上传。行情请求只携带公开股票代码，不携带持仓和偏好。

## 运行时数据流

`设置表单 → storage.js 兼容校验 → localStorage → renderer.js 应用显示/动作/特效 → preload.js IPC → main.js 巡游窗口与行为控制`

最大帧率、模型/特效质量、动作幅度、巡游速度与频率保存后立即生效。更换磁盘上的 GLB、贴图或音频文件属于资源替换，需要重启应用重新加载。

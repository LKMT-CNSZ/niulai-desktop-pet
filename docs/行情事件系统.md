# 牛来盯盘行情事件系统

## 模块边界

- `main.js`：继续负责新浪行情请求、腾讯备用源和约 3 秒轮询，不判断牛的表演。
- `renderer-modules/market-data.js`：保存最新与上一笔行情，并沿用原有持仓盈亏公式。
- `renderer-modules/market-event-engine.js`：把行情流转换为基础状态和一次性事件，负责迟滞、合并、冷却与阈值。
- `renderer-modules/market-event-actions.js`：把基础状态和行情事件映射为动作序列，不读取网络或本地存储。
- `renderer-modules/action-scheduler.js`：处理动作优先级、排队、打断、去重、冷却和安全清空。
- `renderer.js`：负责把事件交给动作、气泡和现有2D/3D控制器。

数据流：行情源 → `MarketStore` → 持仓计算 → `MarketEventEngine` → 动作映射 → `ActionScheduler` → 2D/3D表现。

## 基础状态

- `CLOSED`：休盘，启动原有回家流程并安全中断行情动作。
- `FLAT`：平盘。
- `BULLISH`：普通上涨，只允许开心、挺胸或查看行情的轻动作。
- `BEARISH`：普通下跌，只允许低头、缩肩或轻拖步。
- `DISCONNECTED`：开盘时行情源暂不可用，界面显示自动重连，不触发强动作。

基础状态使用平盘带与迟滞带，价格在边界附近轻微抖动时会保持上一状态，避免来回切换。

## 短时事件

事件包括快速拉升、快速跳水、涨跌幅突破、持仓回本、持仓解套、盈利扩大、盈利明显回撤、涨停和跌停。快速事件按时间窗口比较涨跌幅变化；突破事件按档位锁存并在离开迟滞区后才能重新触发；持仓事件使用原有累计盈亏结果；涨跌停默认按 ±9.8% 判定。

同类事件在合并窗口和冷却时间内只产生一次动作。涨停或跌停与同方向快速/突破事件同一笔出现时，只保留涨跌停完整演出，防止动作叠加。

## 动作优先级

1. 软件退出与安全回家可清空任何动作。
2. 休盘回家高于行情动作。
3. 上香、点击和投喂高于普通行情动作。
4. 极端事件使用排队方式，不会粗暴覆盖正在进行的互动。
5. 普通上涨和下跌只在基础状态真正变化时播放一次轻动作。

行情事件不会自动播放 `niulai.mp3` 或 `mama.mp3`。声音仍只在用户点击牛时，按当天所选股票涨跌决定。

## 阈值与兼容性

默认阈值定义在 `DEFAULT_MARKET_EVENT_CONFIG`。开发面板保存的覆盖项使用新键 `niulai:market-event-settings`，不会改变 `niulai:pet-settings`、`niulai:portfolio` 或 `niulai:selected-symbol` 的含义。缺失字段和旧版本数据会自动补默认值。

主要默认值：

- 平盘带：±0.25%，迟滞 0.08%。
- 快速变化窗口：12 秒；快速拉升/跳水：0.6 个百分点。
- 突破档位：1%、2%、3%、5%、7%。
- 涨跌停：+9.8% / -9.8%。
- 同类事件合并窗口：12 秒。

## 开发模拟入口

开发环境运行：

```powershell
npm run build:renderer
.\node_modules\.bin\electron.cmd . --debug-market
```

左上角会出现“行情事件调试”面板，可模拟全部基础状态和短时事件，也可调整快速变化、突破档位和涨跌停阈值。打包版本不会显示该入口。

自动化检查：

```powershell
npm run test:market
```

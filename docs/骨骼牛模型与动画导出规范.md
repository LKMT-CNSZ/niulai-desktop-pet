# 牛来盯盘：电影造型骨骼牛模型与动画导出规范

## 当前资源与兼容顺序

当前主资源为 `assets/models/bull-rigged.glb`。外形由用户提供的正面、侧面和背面参考图进行多视图连续表面重建，再清理扫描碎片、保拓扑减面、调整腹部和口鼻比例、重绘顶点材质，并转移工程既有骨架与动作。主模型只有一个 42,000 三角面的蒙皮网格，不再用球体、胶囊体等基础几何体拼装角色。它优先保留橙黄色短毛、半睁细眼、粗黑眉、巨大前突粉色口鼻、弯角、角下双耳、粗壮圆身、短粗四肢、分趾牛蹄和尾巴等识别特征。

加载失败时依次回退：

1. `assets/models/bull-rigged-primitive-v3.glb`：连续网格主模型加载失败时使用的第三版骨骼回退牛；
2. `assets/models/bull-rigged-v2.glb`：第二版骨骼回退牛；
3. `assets/models/bull.glb`：旧静态3D资源；
3. Three.js程序化牛；
4. 2D趴窗牛。

`bull-rigged-v1.glb` 继续作为更早的资产备份。任何新版导出都不得覆盖这些回退资源。

## 电影造型约束

- 黄橙色短毛，轮廓不能改成普通奶牛或通用卡通牛。
- 头部偏大、脖子短；肩宽，腹部略圆但不做健美胸腹，也不包含奶头、肚脐或腹部装饰。
- 眼睛细长、半睁，眼皮有重量感；左右眉毛为清晰的粗黑形状。
- 粉色口鼻部是第一识别点：宽、厚、向前突出。上下唇与嘴缝要在80像素高度下仍可分辨。
- 牛角从头顶两侧向外、向上连续弯曲，颜色为灰褐色，材质粗糙；耳朵位于角下方并向左右伸出。
- 手臂和腿偏粗短，脚使用分趾牛蹄，尾巴根部必须连续。
- 正、侧、背面都应有清晰轮廓；侧面必须读出前突口鼻，背面必须读出角、耳和尾巴。

## 拓扑与性能

- 推荐30,000至45,000三角面，硬上限45,000；当前连续网格版为42,000三角面。
- 最多72根骨骼；当前为55根。每顶点最多4个骨骼影响，权重和必须归一化为1。
- 单张贴图不超过2048×2048；桌宠使用短毛 BaseColor、Normal、ORM，禁止高成本实时毛发模拟。
- 肩、肘、膝、嘴角、颈根和尾根保留足够变形环线。关节弯曲侧密度应高于非变形区域。
- 最终人工拓扑可以合并当前分件蒙皮，但骨骼名、动作名、模型朝向和整体比例不得改变。

## 坐标与原点

- 单位为米，Y轴向上，模型正面朝+Z。
- `root` 位于双脚中心的地面投影点，静止姿态最低脚掌Y坐标为0。
- 应用物体旋转和缩放后导出；场景节点默认缩放为 `(1,1,1)`。
- walk/run 不包含桌面根位移；窗口位移由 Electron 主进程控制，动画只表现步态。

## 骨架命名

导出必须满足 `assets/models/bull-rigged.contract.json`。当前55根骨骼覆盖：

- `root`、`pelvis`、`spine_01`、`spine_02`、`chest`、`neck`、`head`、`jaw`；
- `eye_l/r`、`eyelid_l/r`、`brow_l/r`、`ear_l/r`；
- `clavicle_l/r`、`upperarm_l/r`、`lowerarm_l/r`、`hand_l/r`；
- `thumb_01_l/r`、`index_01_l/r`、`middle_01_l/r`；
- `thigh_l/r`、`shin_l/r`、`foot_l/r`、`toe_l/r`；
- `tail_01` 至 `tail_04`；
- `ctrl_look_at`、双手和双脚 IK 目标、双肘和双膝 Pole 目标。

`hoof_hand_l/r` 与 `hoof_l/r` 是旧动画兼容节点，不得在没有迁移代码的情况下删除。

## IK、Look At 与表情

GLB本身不会可靠保存 Blender 的所有约束关系，因此导出文件保留控制骨和链定义，运行时由 `SkeletalAnimationController` 执行 Look At 与轻量 IK。DCC源文件中仍应建立完整约束，方便动画师制作：

- 手臂 IK：clavicle → upperarm → lowerarm → hand，使用 elbow pole；
- 腿部 IK：thigh → shin → foot，使用 knee pole；
- Foot IK 目标控制脚掌位置，toe 保留滚脚和离地动作；
- Look At 控制头部有限角度转向，并以较小权重驱动双眼；
- `blink_l`、`blink_r`、`mouth_open`、`smile`、`frown` 为最低形变集；
- jaw 驱动下唇和张嘴，不能让整个粉色口鼻脱离脸部。

## 动作与关键帧事件

当前GLB包含32个片段：原20个巡游/休眠/行情动作，加上 `blink`、`talk`、`wave`、`point_screen`、`thumbs_up`、`shrug`、`hold_head`、`facepalm`、`nod`、`shake_head`、`jump`、`ear_twitch`。

- 循环片段首尾姿态与速度连续。
- walk/run 的脚掌落地事件和步频必须与桌面位移匹配，不得用模型滑动补偿。
- 冲锋顺序为 `ground_paw → charge → brake → idle_breathe`。
- 关键事件使用契约中的归一化时间，包括脚步、刨地尘、喷气、急停尘、撞击和字效；动作文件不嵌入音频。
- 柔和待机混合建议0.24至0.35秒，转身0.12至0.20秒，冲击动作0.06至0.12秒。

## 权重验收姿势

至少逐项检查：

- wave / point_screen / thumbs_up：肩部不塌陷，手肘不反折；
- hold_head / facepalm：手能到达头脸且不穿过口鼻，颈部不穿模；
- talk / idle_yawn：嘴角连续，下唇随jaw运动，脸部不撕裂；
- walk / run / jump：膝盖方向稳定，Foot IK目标明确，落地不穿地；
- idle_tail：尾根连续且不会断开；
- nod / shake_head：短颈可转动但不穿胸或肩。

## Blender导出步骤

1. 选择可见模型、Armature、Shape Keys 和需要导出的动作。
2. 导出 glTF 2.0 Binary（GLB），启用 Skinning、Shape Keys、Animations。
3. 禁止导出灯光、相机、不可见高模、测试控制器形状和未使用材质。
4. 关闭动画 Simplify 或将误差设为0，保留脚掌落地关键帧。
5. 输出为 `assets/models/bull-rigged.glb`，先保留修改前GLB和契约副本。
6. 执行下面的生成、结构、动作和预览检查。

```bash
npm run model:generate
npm run model:validate
npm run test:animation
npm run model:preview
electron . --debug-actions
```

## 替换资产的验收门槛

- 至少1个 `SkinnedMesh`，骨骼、32个动作和5个形变名称全部满足契约。
- 三角面、骨骼、贴图和每顶点影响数量不超过上限。
- 关键姿势无非有限变换、权重和归一化、Look At 与手脚 IK 能实际改变目标关节。
- 80像素预览仍能辨认粗黑眉、半睁眼、巨大粉色嘴、弯角、耳朵、牛蹄和尾巴。
- 客户端实机加载成功；新版故障时第二版骨骼牛、旧3D和2D回退链可用。

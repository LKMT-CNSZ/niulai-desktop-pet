# 牛来盯盘：统一漫画特效系统

## 分层

系统由 `renderer-modules/effects-manager.js` 统一调度，保留原有特效强度设置、互动特效和音频素材，并划分为六个运行通道：

1. 主文字：短时“牛来！”、“妈妈！”及涨跌停文字；全局只允许一个槽位，新文字会清除旧文字。
2. 动作同步特效：脚掌落地尘、刨地尘、鼻孔白烟、向上冲击环、摔倒星星；只接受 `AnimationMixer` 关键帧事件。
3. 主粒子：红金爆发或绿色下坠线；全局只允许一组。
4. 陪衬粒子：少量金币、泡面或灵魂彩蛋，不占用主粒子槽。
5. 声音：继续使用 `niulai.mp3` 和 `mama.mp3`。为保持现有产品规则，行情演出只记录方向，用户点击牛时才播放；静音和音量设置继续有效。
6. 轻微窗口反馈：冲击时仅对透明画布做2至4像素的短时视觉位移，不移动真实桌面窗口，也不改变家的坐标。

## 行情演出

| 场景 | 动作 | 漫画特效 |
| --- | --- | --- |
| 普通上涨 | happy | “牛来！”、短红金爆发、少量金币 |
| 快速拉升 | ground_paw → charge → brake | 刨地尘、鼻孔白烟、“牛来！”、向上冲击环、少量金币、轻反馈 |
| 普通下跌 | sad | “妈妈！”、绿色下坠线 |
| 快速跳水 | sad → fall → get_up | 下坠线、落地星星、泡面彩蛋、轻反馈 |
| 涨停 | ground_paw → charge → brake → happy | 加强红金爆发、冲击环和金币，但仍保持单主粒子组 |
| 跌停 | sad → fall → get_up | 加强下坠线、星星和灵魂彩蛋 |

绿色气体只保留在“喂大阴线”低频互动中，不用于行情下跌主演出。

## 空间锚点

- 头脸和主文字使用 `head` 骨骼与口鼻局部偏移计算世界坐标，摔倒、冲锋和巡游过程中同步移动。
- 鼻孔白烟使用 `head` 骨骼下左右两个真实鼻孔局部坐标，不使用家园窗口固定点。
- 落地尘读取 `hoof_l`、`hoof_r` 骨骼世界坐标，并只在脚步、刨地或急停关键帧生成。
- 家园和巡游渲染器都运行同一代码，但只有当前实际显示3D牛的窗口获准显示特效。牛在桌面巡游时，家园窗口不会残留主文字或主粒子。

## 强度、省电与休盘

- `petSettings.effects` 继续控制透明度和粒子数量，0表示完全关闭，最大值仍为150%。
- 省电模式把粒子预算降低至约42%，总活动粒子上限由150降至64。
- 休盘睡眠、回家交接和当前窗口不承载3D牛时，主文字、主粒子和窗口反馈会立即清理。
- ZZZ睡眠特效属于低强度生命周期效果，不受高强度行情演出槽影响。

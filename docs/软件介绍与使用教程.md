# 牛来盯盘 · 软件介绍与使用教程

版本：1.4.0 Windows 体验版  
适用系统：Windows 11 x64

## 一、软件介绍

“牛来盯盘”是一款 300×300 像素、透明背景、始终置顶的桌面看盘宠物。它支持 A 股、港股和美股，把用户选择的股票行情、持仓盈亏和趣味互动放在桌面角落。

软件提供两种显示形态：

- 2D 趴窗牛：趴在窗口边缘看着用户，支持呼吸、眨眼、休盘困倦、上涨上探和下跌下沉。
- 3D 动态牛：支持休盘睡觉、上涨冲刺、下跌拖步、头顶涨跌特效及完整 Three.js 互动。

显示形态还提供“自动双形态”：平时使用低刷新率的 2D 守窗牛；关闭省电模式后，快速拉升、快速跳水、涨停或跌停会让 3D 牛从家中自然出门演出。演出结束后可按设置继续巡游，或回家恢复 2D。手动选择 2D 时行情不会强制切换成 3D。

选择 3D 动态牛后，原来的 300×300 挂件会留在原位作为行情、设置和互动控制台，3D 牛则进入独立透明漫游层，在当前屏幕的可用桌面区域自由行走。漫游层只有牛和特效，不会用全屏透明窗口遮挡其他软件；切回 2D 趴窗牛后，漫游层会自动关闭。

3D 牛身后带有柔和的局部暗色轮廓，用于压低桌面网页、代码或文档的高对比文字，避免透明窗口经过文字区域时产生“乱码粘在模型后面”的视觉错觉；轮廓之外仍保持透明。

上涨使用红色，下降使用绿色，符合 A 股常用显示习惯。牛本体在涨跌时保持原色，行情方向通过动作和头顶特效表达。

## 二、开始使用

1. 双击桌面上的“牛来盯盘”快捷方式。
2. 挂件默认出现在主屏幕右下角，并自动恢复上次关闭前的位置。
3. 用鼠标按住顶部中央的 `•••` 手柄，可以把它拖到任意位置。
4. 点击左上角固定行情卡，或 3D 巡游时点击牛身旁的随身行情牌，可打开“我的股票”并选择已经保存的股票；“查看当前详情”展示现价、涨跌、昨收、成交量、成交额、数据源和持仓详情。
5. 点击右上角齿轮，可同时搜索 A 股、港股和美股，分别保存每只股票的持仓，并调整声音、动作与特效。
6. 股票选择页和详情页的“浏览器看盘”会通过系统默认浏览器打开对应的腾讯公开行情页。

## 三、股票市场、搜索与代码

- A 股：支持名称搜索、6 位代码、`sh/sz + 6 位代码`，纯数字会自动识别沪深前缀。
- 港股：支持名称搜索、5 位代码、`hk00700` 或 `00700.HK`。
- 美股：支持公司名称搜索、`AAPL`、`TSLA`、`AAPL.US` 等代码。
- 设置页可任意勾选一个或多个市场，搜索只返回被勾选市场的结果。
- 保存到“我的股票”后，点击左上角行情牌即可快速切换；每只股票的成本与数量单独记忆。

支持以下格式：

- `sh000001`：上证指数。
- `sz399001`：深证成指。
- `sz399006`：创业板指。
- `sh600519`：贵州茅台。
- `sz000001`：平安银行。
- 也可以只输入六位数字。6、5、9 开头自动识别为上海市场，0、3 开头自动识别为深圳市场。

牛身上悬停鼠标并滚动滚轮，可在上证指数、深证成指和创业板指之间快速轮换。

## 四、持仓盈亏

在完整设置中同时填写“成本价”和“持股数”后，底部会显示：

- 今日盈亏 =（当前价 − 昨日收盘价）× 持股数。
- 累计盈亏 =（当前价 − 持仓成本价）× 持股数。
- 累计盈亏率 =（当前价 − 持仓成本价）÷ 持仓成本价 × 100%。

盈利会换算成鸡腿、奶茶、火锅或手机；亏损会换算成少喝奶茶、少吃火锅或“连续吃土”。成本价和持股数必须同时填写，也可以同时留空。

3D 巡游模式的极简行情牌默认只显示股票名称、最新价、涨跌幅和趋势箭头。鼠标悬停后会展开今日盈亏、累计盈亏、成本价、持股数量与同一套生活单位换算；点击后会回到家的“我的股票”面板，再点“查看当前详情”进入专业行情面板。行情断线时行情牌会显示“重连中”，并保留最后一次有效价格供辨认。

## 五、状态说明

- 休盘：工作日 09:30 前、11:30–13:00、15:00 后和周末。牛会进入困倦或睡眠状态并保持静音。
- 平盘：交易时段内价格变化较小时，牛保持轻微呼吸与待机动作。
- 上涨：显示红金上升特效；点击牛身时播放一次“牛来”原声。
- 下跌：显示绿色下降特效；点击牛身时播放一次“妈妈”原声。
- 极端行情：涨跌幅达到约 ±3% 时，会出现金币雨、光环、绿色发带或泡面彩蛋。

行情通常每 3–5 秒刷新一次。网络异常或新浪接口暂时不可用时，软件会保持运行并等待下一次刷新。

软件不会因为行情刷新、涨跌跳变、状态切换或演示动画主动发声。收盘后仍可点击牛身，按当天最后一次成功获取的所选股票涨跌幅播放“牛来”或“妈妈”；平盘、当天尚无行情或行情尚未连接时保持静音。

## 六、互动玩法

- 单击牛身：牛会开心摇摆。
- 约 1.15 秒内连点三次：触发暴躁冲锋和鼻孔烟雾。
- 鼠标悬停：牛会随机吐槽。
- “上香”：升起三炷赛博香并祈祷 15 秒；2D 模式下香炉固定显示在牛的左前方，不会被模型遮挡。
- “喂大阳线”：触发咀嚼、爱心和金币。
- “喂大阴线”：触发摇头、干呕和绿色嫌弃气体。

## 七、设置说明

股票代码输入和持仓页面已统一收入齿轮设置，不再弹出额外的快速输入框。股票详情、设置、说明和退出确认采用互斥显示，打开其中一个时不会与互动栏、盈亏条或其他页面重叠。

- 股票与自选：勾选 A 股、港股、美股，可跨市场同时搜索名称或代码并切换当前标的。
- 持仓：为当前股票设置成本价和持股数量，并选择是否保存到“我的股票”；留空或填 0 表示仅关注、不计算盈亏。
- 2D/3D 模式：支持 2D 守窗、3D 动态和自动双形态；行情牌可跟随 3D 牛或固定在家。
- 桌面巡游：控制是否巡游、是否跨屏、行走速度和出门频率。巡游频率只影响出门与停留节奏，不改变实际行情。
- 回家与睡眠：控制演出结束后是否回家，并提供一键召回。休盘安全回家不受此选项影响。
- 声音：调整原声音效开关和总音量；安静办公时间位于“提醒触发器与安静办公”。
- 动作：控制动作幅度，并可关闭快速拉升、快速跳水、涨停和跌停的完整演出。
- 特效：调整强度和粒子质量，低质量会减少粒子数量。
- 性能：设置省电模式、模型大小、模型质量、特效质量和最大帧率。开启省电后只显示推荐方案，必须点击“应用推荐”才会修改当前表单，不会自动覆盖手动设置。
- 提醒触发器：进入独立页面管理提醒、情绪记忆、收盘总结和安静办公时间。
- 数据与隐私：说明股票、持仓和偏好仅保存在本机，并提供窗口归位和重启提示。
- 顶部 `•••`：按住后由主进程跟随 Windows 鼠标位置移动窗口；全程锁定 300×300，跨不同 DPI 的显示器也不会变大。
- 顶部 `↘`：随时强制恢复为 300×300，并把挂件放回主屏幕右下角。
- 设置内“归位”：作用与顶部 `↘` 相同。
- 恢复默认：只先改动当前表单，点击“保存”后才生效；点击“取消”不会清除原设置。
- 说明：在软件内打开本教程。

设置与多股票持仓使用本机 `localStorage` 保存，窗口位置单独保存在用户数据目录。软件不会上传持仓或用户偏好；搜索和行情请求只会发送公开股票名称或代码。旧版单持仓会自动迁移为多股票记忆，新字段缺失时使用安全默认值。页面中列出的设置保存后即时生效；只有手工替换模型、贴图或音频资源时才需要重启软件。

## 八、本地特色功能

打开齿轮设置，点击标题栏的“特色”进入独立面板。这里可以启用情绪记忆、收盘总结和安静办公，也可以添加价格、涨跌幅、成本、盈亏、快速拉升或快速跳水提醒。

- 新功能默认关闭，旧用户升级后界面和行为不会突然改变。
- 情绪值只影响待机、表情、走动节奏、吐槽和反应幅度，不会修改行情或持仓数字。
- 收盘总结每天最多自动显示一次，可以随时关闭。
- 安静办公支持设置开始和结束时间；启用期间静音、减少特效并降低巡游频率。
- 3D提醒遵守当前形态、省电和安静模式：手动2D不会被强制切换。
- 所有特色数据都只保存在本机。

## 九、退出软件

点击右上角叉叉后会出现确认窗口：

- “继续陪我”：取消退出。
- “确认退出”：正常关闭软件。
- 按 Escape 或点击确认窗口外的遮罩，也会取消退出。

## 十、常见问题

### 行情一直显示连接中

检查网络是否可用，并等待下一次刷新。新浪公开行情接口可能临时限流或调整，软件不会因此退出。

### 牛或特效显示不完整

点击齿轮进入完整设置，适当调小“模型大小”或“特效强度”。也可以点击“归位”。

### 软件重复打开

软件启用了单实例保护。再次双击快捷方式会刷新并唤醒已经运行的窗口，不会产生多个挂件；如果原窗口渲染异常，这次刷新也会自动恢复界面。

### 出现异常提示或窗口消失

日志文件位于：

`C:\Users\当前用户名\AppData\Roaming\niulai-desktop-pet\logs\main.log`

保留日志并记录出现问题前的操作，有助于后续定位。

## 十一、风险提示

本软件展示的数据来自公开行情接口，可能存在延迟、缺失或临时不可用。持仓盈亏仅为本地数学换算，不构成任何投资建议、交易指令或收益承诺。请以券商正式交易系统数据为准。

## 十二、性能与兼容性

- 普通3D渲染目标约为60 FPS；省电模式约为30 FPS。
- 3D牛在家睡眠时约为12 FPS；2D省电睡眠约为8 FPS。
- 软件使用显示器可用工作区的DIP坐标，支持100%、125%和150%缩放以及左右副屏坐标。
- 显示器断开、分辨率变化、锁屏、休眠和唤醒后会先把牛恢复到家的安全位置，再根据开休盘状态决定是否离家。
- 省电推荐必须由用户点击并保存，不会覆盖用户手工设置。
- Windows版未配置商业代码签名证书，首次运行可能出现SmartScreen提示。

## 十三、模块边界（开发说明）

渲染层已拆分为行情与持仓、2D/3D 控制器、行为状态机、动作调度、特效、音频、设置存储、家园窗口和漫游 IPC 十个职责边界。设置仍兼容 `niulai:pet-settings`、`niulai:portfolio`、`niulai:selected-symbol`，字段含义未改变。

行情由主进程获取后通过 IPC 进入行情存储，再分发给界面、持仓计算和行为状态机。2D 牛素材由独立控制器加载，不依赖 `bull.glb`；3D 渲染发生不可恢复错误时会通知主窗口切回 2D。本阶段没有更换 3D 模型，只新增巡游窗口的基础坐标和交互架构。

### 双形态状态机

`displayMode` 继续表示用户保存的偏好，可取 `2d`、`3d` 或 `auto`；主进程的双形态状态机另外维护当前实际形态。自动模式依次经过 `TWO_D_HOME → AUTO_ENTERING → AUTO_PERFORMING → AUTO_ROAMING/AUTO_RETURNING → TWO_D_HOME`。手动3D休盘则进入 `MANUAL_RETURNING → THREE_D_HOME`，继续使用家园睡眠生命周期。形态消息先隐藏旧形态，再显示新形态，因此主窗口和巡游窗口不会同时显示两头牛。行情存储、持仓、基础情绪和事件引擎不随形态重建。

### 巡游窗口基础架构

主窗口是牛的家，巡游窗口是独立的 300×300 透明小窗口。巡游窗口默认鼠标穿透，只在光标进入牛身或随身行情牌的精确交互热区时临时接收操作；移动范围由主进程限制在当前显示器可用工作区内。行情牌和3D牛处于同一窗口、共享同一移动时钟，因此不会出现两个窗口相互追赶造成的拖影或延迟。行情牌会根据牛在显示器中的位置选择左侧或右侧，且始终留在巡游窗口与显示器可用区域内。家移动后会把新的 DIP 屏幕坐标同步给巡游窗口，软件重启后恢复家的位置，3D 牛从家中开始。

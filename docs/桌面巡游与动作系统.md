# 桌面巡游与动作系统

主进程 `main-modules/roaming-behavior.js` 只负责桌面坐标、目标选择、速度、转向、停留、回家和显示器边界。它以1/60秒固定步长推进，不依赖渲染帧率。

主进程通过 `roaming:motion` 发送行为状态、动作名、方向、朝向、速度和步频倍率。渲染进程的 `SkeletalAnimationController` 使用 `THREE.AnimationMixer` 播放真正的GLB动画；没有骨骼动作时，`renderer.js` 根据同一动作名运行旧3D程序姿态。

数据流为：

`设置/行情 → 主进程巡游行为 → roaming:motion → AnimationMixer或旧3D回退 → Three.js渲染`

跨窗口交接另有一条独立数据流：

`开休盘/召回/系统事件 → main.js家园生命周期 → pet:lifecycle → 家园与巡游渲染器 → 可见性、动作与淡入淡出`

默认锁定牛当前所在显示器。开启“跨屏巡游”后，只会选择与当前显示器相邻且有足够重叠的显示器。拖动结束后当前位置成为新的规划起点；双击牛或点击“立即召回”会进入平滑回家状态。休盘强制回家，到达后切换睡眠动作。

省电模式保留固定物理步长，但降低窗口刷新与鼠标热区检测频率，因此速度和轨迹不会因30 FPS或60 FPS发生明显变化。

### 巡游行为细节

- 行为在 `TURN`、`WALK`、`IDLE`、`OBSERVE`、`RETURN_HOME` 和 `AT_HOME` 之间切换，不会持续机械行走。
- 停留时随机选择呼吸、张望、甩尾、挠肚子和打哈欠；`OBSERVE` 会以受限角速度向肩后看，再平滑转回原方向。
- 目标点位于显示器工作区向内22 DIP的安全区域，抵达前按制动距离降低速度；最终吸附半径不超过0.75 DIP，避免最后一帧跳跃或撞边反弹。
- 渲染层使用连续 `heading` 计算3D朝向，并用帧率补偿插值；斜向行走不再只按左右两个方向翻转。
- 回家采用更慢的最高速度和0.5 DIP最终半径，接近家时持续减速并保持朝向入口，抵达后进入 `sleep_enter`。
- 用户拖动结束后以新窗口位置和所在显示器重新规划；双击牛会取消延迟单击并调用平滑召回。
- 默认 `crossDisplayRoaming=false`。开启后只选择相邻显示器，所有位置均使用Electron DIP工作区坐标。
- 省电模式把巡游窗口位置刷新降至约15 Hz、渲染降至约30 FPS、鼠标热区检查降至10 Hz，并延长随机停留时间；内部物理仍固定为1/60秒。

`npm run test:roaming` 会执行30/60 FPS一致性、30分钟长跑、受限转向、五种随机待机、观察回头、目标减速、边缘无反弹、拖动重规划、平滑回家、默认单屏、跨屏、负坐标副屏以及125%/150% DPI工作区测试。结果写入 `artifacts/roaming-behavior-validation.json`。

## 回家、入睡与醒来生命周期

`main-modules/home-lifecycle.js` 定义跨窗口阶段和时间参数；`main.js` 是唯一的阶段协调者。正常休盘依次进入 `RETURNING → ENTERING_HOME → HOME_SLEEP_ENTER → HOME_SLEEPING`。巡游窗口在 `RETURNING` 中继续按固定时间步走向家，抵达0.5 DIP范围后播放850毫秒进门缩放/淡出；随后隐藏巡游窗口，由家园窗口淡入同一3D牛并播放 `sleep_enter` 和 `sleep_loop`。因此两个窗口不会长期重复显示模型，也不会在正常路径中瞬移。

开盘或双击家中睡眠牛时依次进入 `HOME_WAKING → HOME_EXITING → ROAMING`。家园窗口播放 `wake_up`，出门阶段家园牛淡出、巡游牛从家门位置淡入，然后才恢复随机目标规划。休盘时手动唤醒会提供60秒观察时间，之后自动重新回家。

- 家园窗口拖动时会实时更新 `home:bounds` 和行为器的回家目标；拖动结束时不可完整到达的位置会夹回显示器工作区。
- “立即召回”和双击巡游牛均调用同一平滑回家入口，不绕过进门与入睡阶段。
- 关闭桌面巡游后不创建/显示巡游窗口；3D模式继续在300×300家园中醒着或睡眠，2D模式完全不依赖3D生命周期。
- 回家超时、不可跨越的显示器间隙、休眠、锁屏、分辨率变化和显示器断开会进入 `SAFE_HOME`。该阶段使用550毫秒交叉淡变恢复到安全家园位置，并把原因写入 `main.log`。
- 恢复或解锁时，休盘保持睡眠；开盘且允许巡游时重新播放醒来和出门流程。

`npm run test:roaming` 还会执行 `scripts/test-home-lifecycle.js`，检查双窗口可见阶段、过渡时长、动态移动家的回家结果、回家超时上限和强制安全归位。

## AnimationMixer 动作层

`renderer-modules/skeletal-animation-controller.js` 负责将GLB的20个标准片段绑定到 `THREE.AnimationMixer`。循环动作包括 `idle_breathe`、`idle_look`、`idle_tail`、`walk`、`run` 和 `sleep_loop`；其余动作按单次播放并在结束后恢复当前巡游或待机动作。

- 待机与普通走路默认使用0.20至0.32秒柔和混合。
- 左右转身使用0.12秒过渡，模型旋转仍由受限角速度逐帧插值，不瞬间翻面。
- 冲击序列使用0.07至0.10秒快速混合，并按 `ground_paw → charge → brake → 当前巡游动作` 排队。
- `gaitScale` 由桌面实际移动速度除以基础速度得到，并限制在0.35至1.75倍，用来同步步频和窗口位移。
- 非循环动作被高优先级动作打断后，旧动作的结束事件不会覆盖新动作；整段队列结束后只恢复一次巡游姿态。

`renderer-modules/action-scheduler.js` 提供动作优先级、打断、先进先出队列、按动作名称冷却以及最终恢复。持续循环动作必须设置明确持续时间；例如祈祷张望在15秒后释放调度器，不会永久阻塞点击和巡游动作。

## 关键帧事件

事件时间定义在 `assets/models/bull-rigged.contract.json`，由控制器把归一化时间换算为片段时间。当前支持：

- `footstep_left` / `footstep_right`：左右脚落地与轻微尘土；
- `paw_dust`：刨地尘；
- `nostril_smoke`：冲锋喷气；
- `brake_dust`：急停双蹄尘；
- `body_impact`：摔倒撞击尘；
- `impact_text`：冲锋字效；
- `mouth_open`：打哈欠的表情事件。

`EffectsManager` 是隔离的动作事件总线。特效关闭时事件不生成粒子；单个特效监听器异常也不会中断AnimationMixer或触发整个3D渲染回退。

## 开发调试与自动验收

仅在未打包的开发环境运行以下命令时显示动作面板：

```bash
electron . --debug-actions
```

面板可以逐个选择20个动作、强制播放、切换循环、调整速度与混合时间。启用“记录脚掌/撞击关键帧”后，同时显示左右蹄在模型局部坐标中的Y值、相对静止姿态的高度差和XZ漂移，方便检查落地相位。

```bash
npm run test:animation
```

自动测试直接解析真实 `bull-rigged.glb`，检查20个动作均可完成、循环首尾连续、转身角度受限、walk/run没有root位移、步频倍率生效、全部关键帧事件触发，以及优先级、打断、队列、冷却与恢复。walk/run左右脚事件的垂直偏差当前约0.0094至0.0097米，低于0.018米目标。报告输出到 `artifacts/skeletal-animation-validation.json`。

# 牛来盯盘 1.3.1 图标与体积优化报告

日期：2026-08-23

## 本次修复

- Windows 主程序、安装程序和便携版均写入同一套牛来图标资源。
- NSIS 桌面快捷方式和开始菜单快捷方式继续指向主程序图标。
- 安装器、卸载器和安装器页头使用 `build/icon.ico`。
- Three.js 仅作为构建期依赖，运行时使用已经生成的 `renderer.bundle.js`，不再重复打包完整开发模块。
- 排除与主模型内容完全相同的 `bull-rigged-continuous.glb` 副本；主模型和所有故障回退模型均保留。
- Electron 语言包仅保留简体中文和英文。

## 体积结果

- Windows 安装版：84.59 MiB（88,698,887 字节）。
- Windows 便携版：84.08 MiB（88,166,074 字节）。
- 解包目录：256.83 MiB。
- `app.asar`：27.98 MiB。

安装包和便携版均低于 100 MB。安装后的占用仍超过 100 MB，主要原因是 Electron/Chromium 的 Windows 主程序本身约 180 MiB；在继续使用 Electron 和本地 Three.js/WebGL 的前提下，无法把完整安装占用压到 100 MB 内。若未来必须将安装占用也限制在 100 MB，需要另立版本迁移到 WebView2/Tauri 或原生桌面运行时。

## 验证结果

- `npm run test:regression`：通过。
- 连续网格骨骼牛：42,000 三角面、55 根骨骼、32 个动作、5 个表情形态键，校验通过。
- 打包后 EXE 自动启动：通过。
- 2D 素材、3D 模型和动作加载：通过。
- 渲染健康检查：`ready=true`，无渲染错误。
- 自动截图并正常退出：通过。
- 主程序、安装程序、便携版关联图标提取结果一致：通过。
- 测试结束后无残留牛来进程：通过。

## 兼容性

本次不修改任何 `localStorage` 字段含义，不删除行情、持仓、2D/3D、巡游、音频、设置或回退资源。1.3.1 可覆盖安装旧版本，并继续读取当前 Windows 用户目录中的既有设置。

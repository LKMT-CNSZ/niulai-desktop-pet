牛来盯盘 1.3.1｜Windows 安装说明
================================

一、系统要求

1. 操作系统：Windows 10 或 Windows 11。
2. 系统架构：64 位 x64。
3. 建议保持网络连接，以便获取股票行情。
4. 软件已包含运行环境，不需要另外安装 Node.js、Electron 或 Three.js。


二、安装版使用方法

安装文件名称：牛来盯盘-1.3.1-x64.exe

1. 将安装文件保存到电脑本地。
2. 双击“牛来盯盘-1.3.1-x64.exe”。
3. 按照安装向导选择安装位置。
4. 点击“安装”，等待安装完成。
5. 安装结束后，可通过桌面“牛来盯盘”快捷方式启动软件。


三、如果 Windows 显示安全提示

当前体验版尚未配置商业代码签名证书，Windows 可能显示“Windows 已保护你的电脑”。

确认安装包来自可信发送者后，可按以下步骤继续：

1. 点击提示窗口中的“更多信息”。
2. 核对应用名称为“牛来盯盘”。
3. 点击“仍要运行”。

如果杀毒软件拦截，请先核对文件来源，不要关闭 Windows 安全功能或添加整个磁盘为排除项。


四、免安装版使用方法

免安装文件名称：牛来盯盘-1.3.1-portable-x64.exe

1. 将文件放在一个不会随意删除的位置。
2. 双击即可运行，无需安装。
3. 免安装版第一次启动时也可能出现 Windows 安全提示。
4. 不再使用时，正常退出软件后删除该文件即可。


五、首次使用

1. 软件启动后会显示在桌面右下角，并保持置顶。
2. 按住窗口顶部中央的“•••”可以移动挂件。
3. 点击右上角齿轮进入设置。
4. 可填写股票代码、持仓成本和持股数量。
5. 可选择“2D 趴窗牛”或“3D 动态牛”。
6. 选择 3D 动态牛后，控制窗口会留在原位，3D 牛会在桌面区域漫游。
7. 可在设置中调整音量、动作幅度、模型大小、特效强度和漫游速度。
8. 点击左上角行情卡可查看股票详细行情。


六、声音规则

1. 行情上涨时点击牛，播放一次“牛来”。
2. 行情下跌时点击牛，播放一次“妈妈”。
3. 收盘后点击牛身仍会按当天最后一次成功获取的所选股票涨跌幅播放“牛来”或“妈妈”；平盘、当天尚无行情或行情尚未连接时不会播放声音。
4. 软件不会因为行情刷新或状态切换主动发声。


七、退出与卸载

退出软件：

1. 点击挂件右上角“×”。
2. 在确认窗口中点击“确认退出”。

卸载安装版：

1. 打开 Windows“设置”。
2. 进入“应用”→“已安装的应用”。
3. 找到“牛来盯盘”。
4. 点击右侧菜单并选择“卸载”。


八、常见问题

1. 行情一直显示“连接中”
   请检查网络连接并等待数秒。公开行情接口偶尔会出现延迟，软件会自动重试。

2. 窗口位置或大小异常
   点击窗口顶部的“↘”，可恢复 300×300 并回到屏幕右下角。

3. 3D 牛没有显示
   打开设置，将显示形态切换到“2D 趴窗牛”并保存，再切回“3D 动态牛”。如果仍未恢复，请退出后重新启动。

4. 软件无法关闭
   点击右上角“×”，再选择“确认退出”。不要直接反复启动多个副本，软件本身带有单实例保护。

5. 发送给别人时需要发送哪些文件
   一般只需要发送“牛来盯盘-1.3.1-x64.exe”。对方不需要工程源代码或其他资源文件。

十、升级与设置保留

从旧版本升级安装时，股票代码、持仓、音量、显示形态、提醒和窗口偏好继续保存在当前Windows用户目录中。1.3.1不会主动清空或上传这些数据。建议退出旧版本后再运行新安装包；如需回退，可重新运行保留的1.2.1安装包。


九、风险提示

软件使用公开行情接口，数据可能存在延迟、缺失或临时不可用。持仓盈亏仅为本地计算结果，不构成投资建议、交易指令或收益承诺，请以券商正式交易系统为准。

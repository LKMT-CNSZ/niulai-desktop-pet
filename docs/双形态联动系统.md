# 2D守窗牛与3D巡游牛双形态联动

## 职责边界

- `displayMode` 是用户偏好：`2d`、`3d`、`auto`。它继续保存在 `niulai:pet-settings`。
- `FormMorphStateMachine` 是主进程运行时权威，只决定当前实际显示 `2d` 或 `3d`。
- `HOME_PHASE` 继续负责3D牛在家、出门、巡游、返家和睡眠的空间生命周期。
- 行情、持仓、情绪和事件引擎独立于形态状态机，切换时不会清空。
- 主窗口只显示守窗2D或家中3D；巡游窗口只显示离家3D。切换采用先隐藏旧形态、再显示新形态的顺序。

## 状态流

### 手动2D

`TWO_D_HOME`

重要行情仍触发2D动作和文字反馈，但不能请求自动3D窗口。

### 手动3D

开盘：`THREE_D_WAKING → THREE_D_ROAMING`

休盘：`MANUAL_RETURNING → THREE_D_HOME`，随后进入现有3D睡眠循环。

### 自动双形态

日常：`TWO_D_HOME`

重要行情：`AUTO_ENTERING → AUTO_PERFORMING`

演出结束：

- 开启“演后巡游”：`AUTO_ROAMING`。
- 关闭“演后巡游”：`AUTO_RETURNING → TWO_D_HOME`。

巡游渲染器在最后一个骨骼动作关键片段完成后通知主进程结束演出；主进程同时保留超时保护，避免模型动作资源异常时永远停留在演出状态。

休盘、强制召回、显示器安全恢复或退出优先于行情演出。休盘时自动3D会中断强动作，平滑返家后恢复守窗形态；手动3D则留在家中睡觉。

## 自动3D触发条件

同时满足以下条件才允许出门：

1. 用户偏好是 `auto`。
2. 当前实际形态是2D。
3. 已开启桌面巡游。
4. 未开启省电模式。
5. 事件为快速拉升、快速跳水、涨停或跌停。
6. 3D渲染层没有进入故障回退。

涨跌幅突破、回本、解套、盈利扩大和盈利回撤继续使用当前形态反馈，不强制启动3D。

## 故障与兼容

- 3D异常只把运行时形态切到 `FALLBACK_2D`，不改写用户保存的 `displayMode`；用户下次保存设置或重启时可以重试。
- 2D图片加载失败只记录错误，不影响行情卡、专业详情、持仓和设置。
- 旧设置没有 `autoContinueRoaming` 时默认 `false`。
- 旧版 `displayMode` 的 `2d`、`3d` 含义不变。
- 自动模式重启后从 `TWO_D_HOME` 安全启动；手动3D从家的安全坐标启动。

## 回归测试

`npm run test:roaming` 包含双形态状态机测试，覆盖：

- 手动2D拒绝自动3D。
- 省电模式拒绝自动3D。
- 重要与非重要行情分流。
- 自动演出后返家或继续巡游。
- 休盘优先返家。
- 手动2D覆盖自动演出。
- 手动3D返家后保持3D睡眠。
- 3D故障回退但保留用户偏好。
- 保存普通设置不会中断正在进行的自动巡游。
